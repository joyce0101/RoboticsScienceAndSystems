# 10 ms 阶跃响应与停车滑行双档拟合报告（PWM 52/51 & PWM 58/57）

本报告综合分析两组 10 ms（100 Hz）高频阶跃响应与停车滑行实测日志（每组 5 次重复，合计 $n = 10$ 次），换算几何参数采用有效轮径 $r = 16.36\text{ mm}$、有效轮距 $B = 85.8\text{ mm}$、编码器 `358.3 counts/rev`。注：所有时间类参数（$t_d, \tau_{\text{up}}, \tau_{\text{coast}}$）与轮径 $r$ 无关。

## 1. 拟合模型与计算公式

1. **瞬时轮速估算（40 ms 中心差分）**：
   $$v(t_i) = \frac{c_{i+2} - c_{i-2}}{t_{i+2} - t_{i-2}} \times \frac{2\pi r}{358.3} \times 1000\quad (\text{mm/s})$$
2. **稳态轮速 $v_{ss}$**：取 `UP` 阶段 `550–980 ms` 首尾编码器精确斜率（零滤波失真）。
3. **启动阶段 FOPDT（带纯延迟的一阶响应，推荐模型）**：
   $$v(t) = \begin{cases} 0, & t < t_d \\ v_{ss}\!\left(1 - e^{-(t - t_d)/\tau_{\text{up}}}\right), & t \ge t_d \end{cases}$$
4. **停车滑行阶段（一阶指数衰减）**：
   $$v(t) = v_{ss}\,e^{-t/\tau_{\text{coast}}}$$
5. **行程守恒等效时间常数**（不受差分噪声影响，保证总位移精确守恒）：
   $$\tau_{\text{up,eq}} = T_{\text{run}} - \frac{s_{\text{drive}}}{v_{ss}}\times 1000,\qquad \tau_{\text{coast,eq}} = \frac{s_{\text{coast}}}{v_{ss}}\times 1000$$

## 4. 核心结论与推荐仿真参数

1. **两档跨速度高度一致，时间常数与 PWM 基本无关**：`PWM (52, 51)` 与 `PWM (58, 57)` 的所有瞬态时间参数均在 1 倍标准差内高度重合，合并统计（$n = 10$ 启动 / $n = 9$ 滑行）得到：
   - **左轮 FOPDT 启动模型**（$R^2 = 0.9895$）：纯延迟 $t_{d,L} = \mathbf{91.55 \pm 4.95\text{ ms}}$，加速时间常数 $\tau_{\text{up},L} = \mathbf{97.35 \pm 4.83\text{ ms}}$（行程等效总加速 $\tau_{\text{up,eq},L} = 181.42 \pm 5.30\text{ ms}$）。
   - **右轮 FOPDT 启动模型**（$R^2 = 0.9895$）：纯延迟 $t_{d,R} = \mathbf{48.65 \pm 10.21\text{ ms}}$，加速时间常数 $\tau_{\text{up},R} = \mathbf{88.65 \pm 4.37\text{ ms}}$（行程等效总加速 $\tau_{\text{up,eq},R} = 134.01 \pm 8.54\text{ ms}$）。
   - **停车滑行一阶模型**：左轮 $\tau_{\text{coast,eq},L} = \mathbf{114.88 \pm 3.92\text{ ms}}$（曲线拟合 $124.00\text{ ms},\ R^2=0.8703$）；右轮 $\tau_{\text{coast,eq},R} = \mathbf{74.51 \pm 4.47\text{ ms}}$（曲线拟合 $79.44\text{ ms},\ R^2=0.9009$）。
2. **带延迟 FOPDT 显著优于无延迟纯一阶**：加入启动纯延迟 $t_d$ 后，启动段拟合优度从 $R^2 \approx 0.90\text{–}0.94$ 提升至 **$R^2 \approx 0.99$**。
3. **左右轮存在显著动态不对称（直接解释启停偏航）**：左轮启动延迟比右轮多约 **`43 ms`**（`91.6 vs 48.7 ms`），导致驱动阶段机身向左偏航（`+11.1°` / `+12.7°`）；但停车时左轮滑行时间常数也更长（`114.9 vs 74.5 ms`），在滑行阶段向右回摆约 **`-4.1° ~ -4.4°`**，部分抵消了启动偏航。
4. **净动态时间损失**：左轮 **66.54 ± 7.89 ms**、右轮 **59.49 ± 10.32 ms**（启动滞后明显大于停车滑行）。

## 5. 跨数据集一致性核对提醒（写报告前务必确认）

- 这两组日志（`52/51` 与 `58/57`）内部高度自洽，但与 `data/forward_steady/fit.json` 及 `logs/E3_arc_left_*.csv` 存在明显差异：两组稳态轮速分别比 `fit.json` 偏高 **`+3.4% ~ +3.7%`（左）** 与 **`+9.8%`（右）**，且滑行距离（`13–22 mm`）显著大于 `E3_arc_left` 日志中的滑行（`~2–5 mm`）。
- 将本报告拟合的 `t_d / tau_up / tau_coast` 直接代入 `E3_arc_left`（`r=16.36, B=85.8`）仿真时，终点预测误差会从 `9.85 mm` 增大至 `17.38–21.02 mm`。
- **使用边界**：请确认测试所用小车底盘、电池状态及桌面材质是否与 `E3_arc_left` 一致；若两组对应不同小车或不同负载状态，切勿跨车混用参数，以免破坏数字孪生验证的一致性。
